# CodeTrace AI

**Understand your code. Trace your logic. Debug smarter.**

CodeTrace AI is an AI-powered coding assistant that helps developers understand code execution, identify bugs, and debug programs through step-by-step explanations.

## Features

* AI-powered code analysis.
* Step-by-step execution tracing.
* Bug detection and debugging suggestions.
* Variable tracking and execution flow visualization.
* AI-generated code explanations and fixes.

## Tech Stack

* Frontend: React / Next.js
* Backend: Node.js / Express
* AI: LLM API
* Tools: Git and GitHub

*Update the tech stack to match your implementation.*

## Getting Started

```bash
git clone <your-repository-url>
cd CodeTrace-AI
npm install
npm run dev
```

Configure the required environment variables before running the application.
